3. 前端使用分类型详情；当前 note 底部提供证据入口，记忆列表摘要可跳同一详情页；保留 RS 历史与三模式配置。
4. 更新写作 Skill：材料建议标题为“可选的下一步建议”；主 Agent 制定联想问题和关键词；正文就近引用固定依据。无定位信息的旧引用不得臆造位置。
5. 运行相关 Python、组件、类型、真实浏览器验证；更新前端预构建资源和指纹。涉及缓存/来源通道时运行真实 Windows 扩展旧工作区升级及恢复。
6. 核对现行文档、测试登记、索引与校验；记录结果和未解决边界。

## 分工与数据边界

- reading_backend：证据后端、图片、索引警告及类型装配。

- 主 Agent：契约整合、note 行为修复调度、回归、记录与交付。
