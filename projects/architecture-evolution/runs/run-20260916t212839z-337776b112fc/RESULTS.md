# 最近问题笔记、公式引用与证据详情：实施结果

本次完成最近问题选择、轻量笔记显示、编号引用与公式显示、证据搜索和详情跳转。原标准、联想、快速模式及可保存默认配置保留。未发布；运行中的旧工作台需重启后端并刷新页面。

## 使用行为

- “当前阅读笔记”只列最近24小时内容有更新、未归档、有note且当前可访问的RS，按实际更新时间降序。支持分页，保存本浏览器当前选择并按工作区隔离；记忆的选择已不在窗口内则回到最新问题。查看不延长更新时间。
- `context/reading-notes/recent.md`维护相同窗口的导航，每个问题继续维护自己的`<RS-ID>/current.md`。历史RS/修订不删除；静态导航在写笔记或查询最近列表时更新，没有后台时钟任务。
- UI读取已保存展示快照及小型权限元数据，不再先对全部RS进行完整来源核验；首页不再预载全库证据state。来源撤权、记录限制或RS HEAD变化使旧展示失效，按需重建选中问题，不把读快照当成证据复核。
- 正文已知来源显示编号；完整ID、revision、hash和locator保存在引用元数据与深链中。不同版本/块不合并，未知来源不伪造。点击编号可进入证据详情，再跳引用或下游记录。
- “证据与影响”支持标题、结论/整体概览、ID搜索。左侧定位记录，右侧按需展示正文、标签、关键上下文、依据及直接下游关系。覆盖MEM、Owner/Run、兼容claim和已登记SRC；文件来源显示登记信息与定位，不虚称已读原件。固定版本不匹配时不静默换成当前版。
- 数学渲染支持`$...$`、`$$...$$`和常见`\(...\)`、`\[...\]`，保护代码字面量；新reader派工明确要求数学分隔符。

## 主Agent实际接收什么

主Agent仍调用`reading-handoff`，接收其中的`context_markdown`、固定引用、覆盖情况与缺口。它没有直接盲读磁盘`current.md`：RS JSON仍是权威状态，磁盘Markdown是面向阅读的派生副本。AI交接使用短编号，完整来源保留在references；UI的链接排版采用独立30,000字符展示窗口，不能把链接装饰计入AI原note预算而挤掉内容。
