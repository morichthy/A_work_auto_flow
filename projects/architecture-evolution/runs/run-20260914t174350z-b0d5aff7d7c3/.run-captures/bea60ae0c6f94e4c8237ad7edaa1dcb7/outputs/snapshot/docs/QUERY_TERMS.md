# 中英术语与关联扩展维护

本页维护AI材料查询的词库格式、使用边界与升级方式；查询计划字段和调用见[AI_READING](AI_READING.md)。词库是检索辅助配置，不是业务结论或替代原文的知识库。

## 文件与维护责任

- 日常维护唯一位置：[retrieval/query-terms.json](../retrieval/query-terms.json)。AI或用户在真实阅读发现可靠对应关系后编辑，保留稳定id、领域和出处；禁用用status=disabled，不悄悄改成另一个含义。
- 公共种子：[automation/templates/query-terms.default.json](../automation/templates/query-terms.default.json)。初始8条信息检索领域术语只用于起步，不宣称覆盖公司算法/专业语料。sources提供核查入口；中文译名和related关系是本次AI整理的检索建议，active表示启用，不表示科学结论已复核。
- 用户库不进入公共源码包；安装/升级只在缺失时从公共模板补齐，已有用户词条保持原字节。更换公共模板不批量改用户库。
- 旧工作区直接换源码而未运行setup时，先检查目标是否存在，仅在缺失时复制上述模板；禁止覆盖已有库。私有词条/来源不得加入公共模板。维护前保留旧文件或Git历史，写后检查JSON与实际查询追踪。

## 格式

顶层为schema_version=1和entries数组。每项字段：

| 字段 | 含义与约束 |
|---|---|
| id | 稳定且唯一的词条身份；语义改变时另建条目 |
| domain | 领域字符串；通用词可general，多义词必须具体领域 |
| zh / en | 本领域等义中文/英文术语数组；上下位概念不能放这里 |
| aliases | 同一概念的缩写、别名；有歧义的缩写依领域使用 |
| related | 单跳关联检索词数组；因果/上下位/相邻方法等只表示查阅候选 |
| sources | 非空出处字符串数组；公共文献URL或获准的本地固定引用，不伪造版本/出处 |
| status | active启用，disabled停用；不表示复核状态 |

示例为初始种子的一个条目：

```json
{
  "id": "reciprocal-rank-fusion",
  "domain": "information-retrieval",
  "zh": ["倒数排名融合"],
  "en": ["reciprocal rank fusion"],
  "aliases": ["RRF"],
  "related": ["hybrid search", "rank fusion"],
  "sources": ["https://www.elastic.co/docs/reference/elasticsearch/rest-apis/reciprocal-rank-fusion"],
  "status": "active"
}
```

query_domains选择本次领域；程序使用general与匹配领域的active条目。不要为强制命中把所有术语标general。相关词不递归展开，不能从一个命中无限扩到其他领域。自然语言翻译与是否适用仍由AI判断，词库不会自行调用翻译模型。

## 每次查询怎么使用

1. AI从已有获准语料判断语言和领域；不能仅凭首批命中假定全库语言。技术问题、明显文献依赖或可靠英文来源/数据流，即使中文提问也增加英文关键词和完整语句。保存判断依据；来源可靠性取决于出处/内容，不由语言保证。
2. 保留原问题，生成最多3条去重等义查询；lexical_terms只放紧凑术语、型号、别名，question保留完整条件。实体原名、型号、版本、数值及单位/范围/否定不能被扩词替换。
3. 每次新召回从词库匹配同义与关联。无匹配或缺文件在追踪中可见；无条目时不能假装做过有效扩词，AI按真实材料补库后开展明确新一轮。旧词库内容错误时修订/禁用并保留修改理由；已保存查询不回写。
4. 同义词补词法，related走独立较低权重词法路；向量仍使用完整等义句。跨路排名融合，输出固定记录与块、各路query来源和词库指纹。关联命中须由AI解释连接，不能作为答案支持直接采纳。
5. 续页复用该轮冻结计划；词库更新不会改变已发生查询。各路共享原预算，更多查询不是免费；预算耗尽明确报告覆盖缺口。

程序检查格式和受保护文本，不能证明译文等义或候选满足条件。AI阅读固定正文后，将满足/冲突/未说明及其依据记录到reading-note；不能把“0.5”出现解释成“误差≤0.5 mm成立”。

## 验证和适用范围

先针对实际失败问题比较原查询、双语等义、加入同义与关联扩展。保留固定语料、模型/索引版本、每路命中、预算与延迟，衡量相关证据召回和错型号/版本，避免用命中数量宣称收益。种子词库仅覆盖示例领域，实际业务领域需要真实材料逐步维护。

自动词库读取和多查询融合接在reading-recall阅读入口；AI应按material-query Skill通过此入口执行上述策略。工作台手动普通查询和旧查询接口仍沿各自契约，不在后台自动调用AI翻译。手动填写多语关键词不等于程序已经执行了完整双语计划。
